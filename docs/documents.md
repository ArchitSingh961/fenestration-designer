# Quote documents

Every saved quote has a **Documents** tab (Sales › Documents, or **Documents** in the quote's header): the files that
belong to the quote, by category, in the same database as the quote (schema 10, `project_documents`).

| Category | What goes there |
|---|---|
| Pre Production Survey Report | the site survey: measurements, photos, notes (upload) |
| Quotations | **every quotation PDF MARK writes is kept here automatically** ("Quotation QT-00012 R1"), and any uploaded |
| Margins | **Make margin report**: cost, price and margin of every design, then each design's cost sheet line by line (for the company, not the client) |
| Credit Approval | credit forms and approvals (upload) |
| Sales Order/Contract | the signed order or contract (upload) |
| Others | anything else (upload) |
| Typology History | the designs of the quote now and of every saved revision (R0, R1…: reference, size, quantity, value), and uploads |

- **Upload** adds any file (PDF, picture, document…) up to 25 MB to the category shown, with who added it and when.
- **Search** finds by name, file name or who added it; **Sort by** newest, oldest, name or size.
- Each file can be **opened** (a temporary copy opens in its program), **saved as a copy**, or **deleted** (asked first).
- A quote must be saved before files can be kept with it. Read-only logins can open and save copies, not add or delete.

The margin report counts as **cost** each window's basic value without the cost lines named *Profit* or *Margin*;
**price** is after the discount, before charges and tax; **margin = price − cost** (also as % of the price).
